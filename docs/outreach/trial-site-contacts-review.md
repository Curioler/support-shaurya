# Trial site contacts — review of the raw list

Derived from [the raw list](../sources/2026-08-15-clinical-trial-site-contacts.md).

**Nothing in this file is verified.** It records which entries look wrong and why. Do not
send mail to a "likely" address below — corrections are inferences, and a plausible-looking
wrong address is more dangerous than an obviously broken one. Every row needs confirming
against the institution's own site or its ClinicalTrials.gov record before use.

## Why this matters

If the family has been working through this list and hearing nothing back, undeliverable
addresses are a likely cause. Bounces to a mistyped domain are easy to miss in a busy
inbox, and mail to a *valid but wrong* domain vanishes with no bounce at all. Several
entries below fall in that second category.
